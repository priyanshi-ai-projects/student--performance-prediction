# Student Performance Prediction

## About the Project
This is a beginner machine learning project to predict student performance using student-related features.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Model Evaluation
- Mean Absolute Error (MAE): 2.21
- R-squared (R²): 0.15

## Purpose
This project helped me learn the basics of regression, model training, and model evaluation.
